## 目录结构

```text

    └── paper.pdf
```

- `papers/`：存放论文笔记。
- 每篇论文使用一个独立子文件夹。
- `README.md`：论文信息、核心方法、实验结果和个人思考。
- `paper.pdf`：论文原文。
