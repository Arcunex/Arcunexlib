## 论文解决什么问题

完整、精确的人类网球 MoCap 数据很难采集：比赛空间大、连续交互时间长，挥拍时腕部动作又快又容易受遮挡。LATENT 不要求完整比赛轨迹，只采集正手、反手、侧滑步和交叉步等“不完整且不精确”的动作片段，再通过强化学习把这些片段校正并组合成可执行的网球策略。

## 方法链路

1. **动作片段采集与重定向**：5 名业余选手、约 5 小时数据，采集原语而非完整回合，并通过 LocoMuJoCo 重定向到 G1。
2. **Tracker 预训练**：使用 Any2Track 风格的 PPO motion tracker，将噪声参考动作转成物理可执行动作。为了给后续腕部修正留下空间，训练时去掉持拍腕关节的参考控制并对其施加扰动。
3. **在线蒸馏与潜在动作空间**：通过 DAgger 将 tracker 蒸馏为带条件变分信息瓶颈的 encoder-decoder。后验编码当前状态和下一帧参考，条件先验只依赖当前状态，decoder 输出身体动作。
4. **高层网球策略**：高层策略根据机器人状态、全局根部状态和球状态，输出潜变量以及持拍腕部的直接修正量，实现步法、击球原语的组合和精细拍面控制。
5. **Latent Action Barrier（LAB）**：围绕状态条件先验的均值，用其标准差缩放残差潜变量并经 `tanh` 限幅，限制 PPO 钻出动作流形，减少抖动和不自然的原语切换。
6. **Sim-to-Real**：随机化机器人与球的动力学，对观测加入噪声、丢帧和延迟；球速由四帧滑动窗口估计。控制器和高层规划均为 50 Hz，仿真为 2000 Hz。

## 关键结果

- 仿真中，LATENT 在正手/反手成功率上达到 **96.52% / 82.10%**；同表中的 PULSE 为 **71.85% / 63.38%**。
- 去掉腕部修正后，正手/反手成功率降至 **82.36% / 68.94%**。
- 去掉 LAB 后动作更抖、平均力矩更高，证明“受约束地修正动作先验”是核心。
- 真机消融显示，动力学随机化和球观测噪声建模对迁移非常关键。
- 真机仍依赖大范围光学 MoCap；论文将主动视觉和多智能体真实比赛列为后续方向。

## 简单评价

**优势**：把不完美数据拆成“可执行技能学习”和“任务级组合/修正”两个问题；潜在动作空间与腕部显式修正结合，兼顾全身自然性和毫秒级击球精度；紧耦合策略只需要当前球状态即可快速反应。

**局限**：完整系统复现成本高，论文真机感知依赖 MoCap；任务主要是将随机来球回到目标区域，并非完整规则下的对手建模；截至建档时，官方仓库仅释放 tracker 与少量动作数据，DAgger、latent model、高层策略和完整 sim-to-real 代码仍在 TODO 中。

## 阅读结论

LATENT 的核心不是“用 VAE 生成一条动作轨迹”，而是把已训练 tracker 的可执行动作能力压缩成状态条件 latent action space，再由高层 PPO 在受 LAB 约束的潜空间中组合技能，同时单独修正最需要精度的持拍腕部。它更偏向**任务性能和快速反应**。
